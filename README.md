# 济鸣（Ji Ming）


同济 Canvas 作业与课表助手的 Android 安装包。

> 数据来自 `canvas.tongji.edu.cn` 与 `1.tongji.edu.cn`，使用同济统一身份认证登录。

## 下载安装

从 [Releases](../../releases) 下载最新的 `济鸣-v2.0.apk`，传到手机后点击安装。

- 安卓 10+ 无需存储权限即可下载附件
- 首次安装需要联网登录一次同济统一身份认证
- 支持断网查看已缓存的作业、课表、考试、成绩

## 功能

- **待办**：Canvas 作业列表、提交状态检测、逾期已完成可删除
- **课表**：按第几周 / 单双周显示真正要上的课，支持正在上 / 下一节提醒
- **考试**：教务考试安排，临近考试开放时自动出现
- **文件**：课程文件下载到 `Download/济鸣/`
- **成绩**：成绩与绩点、绩点分布
- **通知**：Canvas 新通知、作业临近截止、上课与考试提醒
- **离线**：本地缓存作业 / 课表 / 考试 / 成绩，断网也能查看
- **自启动**：杀进程 / 重启后自动恢复登录态并继续提醒

## 安装后

打开 App，点「用学校账号登录」，用同济统一身份认证登录一次即可同时接通 Canvas 与教务系统。
不建议清除 App 数据，否则需要重新登录（登录态保存在本机）。
